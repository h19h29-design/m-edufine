# M-에듀파인 — Mdir 스타일 Windows 키보드 클라이언트

**v0.2.0 Preview · 비공식 · 실제 K-에듀파인 기관 계정 호환성은 현장검증 전입니다.**

웹 화면을 가짜로 복제하거나 별도 업무 DB에 저장하지 않습니다. 사용자가 **실제 Edge/Chrome에서 로그인한 탭**을 연결하고, 그 화면에서 읽은 메뉴·버튼·입력란·표를 Windows 프로그램에 표시합니다. 방향키와 기능키로 실제 웹 요소를 조작합니다.

> **완성된 K-에듀파인 전체 복제품이 아닙니다.** 인증 후 전용 그리드·내부 메뉴 구조를 확인하지 못한 상태에서 개발한 **실제 브라우저 연결형 프리뷰**입니다. 현재 화면의 일반 DOM 요소를 다루며, 인식 불가 화면과 결재·지급·삭제는 원본 웹에서 처리합니다. 로그인과 서버 저장 성공을 추측해 표시하지 않습니다.

## 다운로드

[Windows 설치파일 및 검증 결과](https://github.com/h19h29-design/m-edufine/releases/tag/v0.2.0)

- `M-Edufine-Setup-0.2.0-win-x64.exe`: 일반 사용자 권한 설치. .NET 실행환경 포함.
- `M-Edufine-0.2.0-win-x64.zip`: portable 전체 패키지.
- `M-Edufine-Extension-0.2.0.zip`: 브라우저 확장 별도 패키지.
- `SHA256SUMS.txt`: 다운로드 파일 해시.
- `M-Edufine-QA-0.2.0.zip`: 실제 수행한 테스트 결과와 Windows 화면 이미지.

릴리스가 보이지 않으면 [Windows build](https://github.com/h19h29-design/m-edufine/actions) 상태를 확인하세요. 소스에 설치 빌드 설정이 있다는 사실과 실제 설치파일 배포 성공은 다릅니다.

## 0.2.0 변경사항과 한계

- 실제 사용자 화면에 상위 메뉴(일정관리·문서관리·업무관리·기능분류 등)가 보이지만 v0.1.0에서 일부 버튼만 인식하는 문제를 확인했습니다.
- 클릭 처리된 `li`/`span`/`div` 및 메뉴·탭 컨테이너의 포인터 항목을 추가로 인식합니다.
- 왼쪽 분류에서 Enter/→ 로 오른쪽 항목에 포커스를 이동하고, 왼쪽 방향키로 분류에 돌아옵니다. 항목 Enter 실행 시 F7 허용 및 개별 실행 확인은 유지합니다.
- **인식 결과는 기관·화면마다 다를 수 있습니다. 실제 K-에듀파인 메뉴 전부가 구현됐다는 뜻이 아닙니다.** 표시되지 않거나 비활성인 메뉴는 원본 웹(F4)에서 처리합니다. 원본 브라우저의 접근성 모드(Ctrl+Space)가 키보드 접근에 도움이 될 수 있습니다.
- 브라우저 화면에 읽기 전용 업무 데이터가 표시되면 외부에 스크린샷이나 로그를 공유하기 전에 개인정보를 지우세요.

## 처음 사용하는 방법

1. 설치파일을 실행합니다. 관리자 권한은 요구하지 않습니다.
2. 앱에서 **F1 → 확장 폴더 열기**를 누릅니다. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축 풀린 확장 로드**로 그 폴더를 선택합니다. Edge는 `edge://extensions`를 사용합니다.
3. **F9**로 실제 기관 업무 사이트를 열고, 평소처럼 인증서 로그인합니다. 기본 브라우저가 Edge/Chrome이 아니면 해당 브라우저에서 직접 여세요.
4. K-에듀파인 업무 탭에서 브라우저 확장 **M-에듀파인 연결 → 이 탭 연결**을 누릅니다.
5. 앱으로 돌아와 **F5**를 누르면 현재 화면의 실제 항목을 읽습니다. 처음에는 **읽기 전용**입니다.
6. 실제 조작이 필요하면 **F7**로 이번 연결의 입력·클릭을 허용합니다. 항목 선택 후 **Enter** 또는 **F2**로 실행합니다.

인증서/비밀번호는 이 앱에 입력하지 않습니다. 최초 확장 로드는 한 번만 필요합니다. 기관이 개발자 모드·확장·Native Messaging을 차단한 경우 승인·관리 배포가 선행되어야 하며, 이 프로그램은 정책을 우회하지 않습니다. 확장이 Edge Add-ons에 게시된 제품은 아닙니다.

### 설치 환경

Windows 11 x64 또는 지원되는 Windows 10 x64 환경, Edge 또는 Chrome, 실제 기관 업무망/승인된 EVPN 접속이 필요합니다. Windows 7/8, IE 모드/ActiveX 화면과 ARM64 네이티브 빌드는 대상이 아닙니다. Windows 10의 OS 지원 자격은 기관에서 별도 확인해야 합니다. 코드서명 인증서는 적용하지 않았습니다. 기관 보안 경고가 발생하면 보안 프로그램을 끄지 말고 관리자에게 검토를 요청하세요.

### Portable 사용

ZIP 전체를 같은 폴더에 풀고 PowerShell에서 다음을 실행해 현재 사용자에 연결 호스트를 등록합니다. EXE 하나만 옮기면 실행환경과 확장이 빠집니다.

```powershell
& '.\tools\Register-Bridge.ps1'
& '.\M-Edufine.exe'
```

PowerShell 실행 정책이 스크립트를 차단하면 정책을 임의로 우회하지 말고 일반 설치파일 또는 승인된 배포 방법을 사용하세요. 설치형은 등록 스크립트를 실행할 필요가 없습니다.

## 실제 데이터 연결 방식

```text
사용자 키 입력
  → Windows WPF 앱 (자체 업무 DB 없음)
  → 현재 Windows 사용자 전용 Named Pipe
  → Native Messaging 호스트
  → 사용자가 직접 연결한 Edge/Chrome 확장
  → 실제 로그인된 탭의 DOM 입력·클릭
  → 기존 K-에듀파인 웹 애플리케이션이 원래 방식으로 서버 처리
```

공식 API를 얻었다고 가정하지 않고, 내부 비공개 API를 추정 호출하지 않습니다. 기존 웹 앱의 보안·업무 검증을 그대로 거칩니다. **웹 버튼 클릭 전달 ≠ 서버 저장 성공**입니다. 입력값 변경만으로 자동 저장하는 웹 화면도 있으므로 F7 및 입력 확인을 반드시 거칩니다. 서버 저장 결과는 원본의 메시지와 실제 조회로 확인해야 합니다.

F5는 다른 사용자가 방금 수정한 서버 데이터를 강제로 가져오지 않습니다. 먼저 원본의 실제 **조회** 동작을 실행하고 F5로 결과를 읽으세요. 읽기 시각을 표시하며, 페이지 전환/탭 종료/연결 해제 시 기존 목록을 지웁니다. 오래된 화면 ID, 삭제된 요소, 값이 바뀐 입력란에는 쓰지 않습니다. 오류·시간초과 후 변경 요청을 자동으로 반복하지 않습니다.

## 포함한 기능 / 아직 확인하지 못한 기능

| 구분 | 상태 |
|---|---|
| Mdir 색상·2패널 Windows 화면, 한글, 키보드 탐색 | 구현 |
| 실제 브라우저 탭 연결, 사용자 전용 통신 | 구현, Windows 프로토콜 테스트 대상 |
| 일반 링크·버튼·입력·선택·체크, 열린 Shadow DOM | 구현, 로컬 Chromium 테스트 대상 |
| 허용된 각 프레임 읽기 | 구현. 허용되지 않은 프레임은 건너뛰고 수 표시 |
| 실제 입력/클릭 전달, 중복 실행 방지, 오래된 대상 차단 | 구현, 로컬 Chromium 테스트 대상 |
| Windows 설치·제거, 확장 포함, portable | 빌드 파이프라인 포함. 성공 증거는 Release/Actions 확인 |
| 실제 서울 K-에듀파인 인증 후 물품·계약·지출 메뉴 | **미검증** |
| 전용 프레임워크/캔버스/폐쇄 Shadow DOM/가상 스크롤 전체 행 | **미지원 또는 미검증**. F4 사용 |
| 결재·승인·지급·송금·삭제 등 중요 업무의 원격 클릭 | **의도적으로 실행하지 않음**. 원본 웹에서 최종 처리 |
| DB 복제·오프라인 업무 저장·백그라운드 일괄 제출 | 제공하지 않음 |

표는 최대 6개/프레임, 120행/표, 30열을 읽고, 일반 항목은 400개/프레임, 프레임은 24개까지 처리합니다. 상한/전송 크기로 일부만 표시되면 화면에 알립니다. 가상 스크롤의 아직 로딩하지 않은 행은 포함되지 않습니다. 새 팝업 또는 새 탭은 **그 창에서 확장 → 이 탭 연결**을 다시 누릅니다.

## 개인정보·보안

- 외부 AI, 클라우드 서버, 분석/광고/텔레메트리 SDK 없음. 로컬 HTTP/WebSocket 수신 포트도 없음.
- 인증서·비밀번호·숨김 토큰·파일 입력을 읽거나 전송하지 않음. 보호된 이름의 입력과 표 열 및 주민번호 형태 문자열을 필터링함. 이 필터가 모든 민감정보를 식별한다는 보장은 없으므로 업무 자료를 외부에 공유하지 마세요.
- 원본 브라우저의 로그인 세션과 쿠키를 **추출하거나 다른 브라우저로 복사하지 않음**.
- 웹 내용은 메모리 표시 전용. `%LOCALAPPDATA%\M-Edufine\settings.json`에는 시작 주소와 글자 크기만 저장.
- Native Messaging 허용 확장 ID 고정, Windows 현재 사용자 전용 파이프, 최대 메시지 크기·JSON 깊이 제한.
- 확장은 사용자가 연결한 한 탭에 고정. 기본 허용은 `klef.sen.go.kr`, `sen.eduptl.kr`. 추가 기관 HTTPS 주소는 사용자 승인으로 개별 부여.
- 앱 제거 시 앱·호스트 등록을 제거하지만 브라우저 프로필·업무 데이터·사용자 설정은 삭제하지 않음. 확장은 브라우저에서 별도 제거.

## 개발·빌드

.NET 10 SDK와 Windows에서:

```powershell
dotnet publish '.\src\MEdufine\MEdufine.csproj' -c Release -r win-x64 --self-contained true -o '.\publish'
Copy-Item '.\extension' '.\publish\extension' -Recurse -Force
Copy-Item '.\native-host.json' '.\publish\native-host.json' -Force
& '.\publish\M-Edufine.exe' --self-test
```

전체 설치 패키지는 `.github/workflows/windows.yml`에서 코드 검사 → Chromium DOM 테스트 → Windows .NET 빌드 → 네이티브 통신 테스트 → WPF 렌더 스모크 테스트 → Inno Setup 설치·제거 시험 → Preview Release 순으로 만듭니다. 실제 기관 로그인/저장 검증은 자동 테스트로 대체할 수 없습니다.

# M-에듀파인 — Mdir 스타일 Windows 키보드 클라이언트

**v0.3.0 Preview · 비공식 · 검증 범위는 아래 표에 적은 부분만 해당합니다.**

웹 화면을 복제하거나 별도 업무 DB에 저장하지 않습니다. 사용자가 **실제 Chrome/Edge에서 로그인한 탭**을 연결하면, 그 화면에서 읽은 **업무 메뉴 트리**와 버튼·입력란·표를 Windows 프로그램에 표시합니다. 방향키와 기능키로 실제 웹 요소를 조작합니다.

> **완성된 K-에듀파인 복제품이 아닙니다.** 2026-10-31에 실제 기관 로그인 세션에서 **읽기 전용**으로 확인한 범위는 `docs/QA-0.3.0.md`에 비식별로 기록했습니다. 화면 구조·권한·프레임에 따라 읽지 못하는 메뉴가 있으며, 그때는 F4 원본 웹을 사용합니다. 로그인과 서버 저장 성공을 추측해 표시하지 않습니다.

## 0.3.0 변경사항

### Mdir형 3패널 화면
- **왼쪽: 실제 업무 메뉴 트리** — 이전 버전의 고정 분류(전체/메뉴/버튼/입력)를 없애고, 현재 화면에서 읽은 `업무관리 > 계약관리 > 계약요청` 같은 **계층 메뉴**를 표시합니다.
- **오른쪽: 선택한 메뉴의 하위 메뉴 + 실제 항목** — 폴더(▸)와 실행 항목, 입력란 현재 값을 한 목록에 표시합니다.
- **상단: 기관·경로·연결/읽기 상태**, **하단: 기능키 안내**.
- 큰 한글 글꼴, Per-monitor DPI v2, 125~150% 배율 대응.

### 메뉴 인식 개선
- `button/a` 뿐 아니라 실제 업무 포털이 쓰는 `div/span/li` **위임 클릭 메뉴**를 읽습니다.
- **이미지 전용 메뉴**는 `img alt`/`aria-label`로 이름을 복원합니다.
- DOM 중첩으로 **상위/하위 경로**를 만들고, 같은 이름의 메뉴는 **프레임·경로·영역**으로 구분합니다.
- 클래스명·id가 그대로 노출되는 기술적 이름은 메뉴로 표시하지 않습니다.
- 클릭은 `pointerdown → mousedown → pointerup → mouseup → click` 순서로 전달해, `mousedown`에만 반응하는 포털 메뉴도 동작합니다.

### 상태 보존과 전환
- F5로 다시 읽어도 **선택한 메뉴 경로·검색어·포커스 패널**을 복원합니다.
- **Ctrl+F4 업무 탭 전환**: 열려 있는 기관 HTTPS 탭 목록에서 연결 대상을 바꿉니다(새 창/팝업으로 열린 업무 탭 대응).
- 표 보기는 실제 **열 머리글**을 사용합니다.
- 화면 전환·탭 종료·연결 해제 시 이전 목록을 지웁니다.

### 안전 기본값 유지
- 최초 연결은 **읽기 전용**. F7로 이번 연결만 조작 허용.
- 실행 전 항목별 확인, 결재·지급·삭제 등 고위험 라벨은 원본 웹 안내로 전환.
- 웹 클릭 전달 ≠ 서버 저장 성공. F5는 **현재 DOM 재읽기**이며 서버 재조회가 아닙니다.

### 수정된 실제 오류
- 여러 인스턴스가 있을 때 `--self-test`가 기존 앱의 파이프에 붙어 멈추던 문제 → 시험 전용 파이프로 격리.
- 트리 항목의 접근성 이름이 `MEdufine.MenuNode`로 노출되던 문제 → 실제 메뉴 이름 노출.
- 검색을 지운 뒤 상단 메타가 이전 검색 문구로 남던 문제.
- 프로그램이 표 행을 선택하며 포커스를 빼앗아 Enter가 엉뚱한 항목에 적용되던 문제.
- DRM 프로그램이 붙인 브라우저 제목 접미사가 화면 제목에 섞이던 문제.

## 실제로 확인한 범위 (2026-10-31, 읽기 전용)

| 화면 | 확인한 것 | 결과 |
|---|---|---|
| 기관 업무포털 메인 | 상단 업무 메뉴, 바로가기, 현황 카드 | 메뉴 25개·항목 230개 읽음. 프레임 1개 접근 불가 |
| K-에듀파인 메인 | 상단 업무 영역, 좌측 메뉴, 통합검색 | 메뉴 11개·항목 92개 읽음. 제목 정상 표시 |
| 메뉴 실행 | 포털의 K-에듀파인 이동 | 실제로 K-에듀파인으로 이동함 |
| 업무관리·문서관리·물품·계약·예산 하위 화면 | — | **미검증** |
| 조회 실행·결과 비교·저장 | — | **미검증** (운영 데이터 변경 금지) |

- K-에듀파인 상단의 **업무관리·문서관리·자료실** 3개는 현재 추출기로 읽지 못했습니다. 구조가 다른 위젯으로 판단되며, 이 항목은 F4 원본 웹에서 선택해야 합니다.
- 새 창을 여는 메뉴는 Chrome의 사용자 활성화 요구로 **자동 클릭이 차단**될 수 있습니다. 이때는 원본에서 한 번 열고 **Ctrl+F4**로 그 탭에 연결하세요.
- 위 수치는 비식별 구조 수치이며, 문서 제목·개인정보·기관 식별자는 기록하지 않았습니다.

## 처음 사용하는 방법

1. 설치파일을 실행합니다. 관리자 권한은 요구하지 않습니다.
2. 앱에서 **F1 → 확장 폴더 열기**를 누릅니다. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축 풀린 확장 로드**로 그 폴더를 선택합니다. Edge는 `edge://extensions`를 사용합니다.
3. **F9**로 실제 기관 업무 사이트를 열고, 평소처럼 인증서 로그인합니다.
4. 업무 탭에서 확장 **M-에듀파인 연결 → 이 탭 연결**을 누릅니다.
5. 앱으로 돌아와 **F5**를 누릅니다. 왼쪽에 실제 메뉴 트리가 표시됩니다.
6. 방향키로 메뉴를 이동하고 **Enter**로 폴더를 펼치거나 항목을 실행합니다. 실행에는 **F7 허용**과 항목별 확인이 필요합니다.

인증서/비밀번호는 이 앱에 입력하지 않습니다. 기관이 개발자 모드·확장·Native Messaging을 차단한 경우 승인·관리 배포가 선행되어야 하며, 이 프로그램은 정책을 우회하지 않습니다.

### 설치 환경

Windows 11 x64 또는 지원되는 Windows 10 x64, Chrome/Edge, 실제 기관 업무망/승인된 EVPN. Windows 7/8, IE 모드/ActiveX, ARM64 네이티브는 대상이 아닙니다. 코드서명 인증서는 적용하지 않았습니다.

### Portable 사용

```powershell
& '.\tools\Register-Bridge.ps1'
& '.\M-Edufine.exe'
```

## 단축키

| 키 | 기능 |
|---|---|
| ↑↓ | 왼쪽 메뉴 트리 / 오른쪽 목록 이동 |
| → | 폴더 펼치고 오른쪽 목록으로, 목록에서 하위 항목 |
| ← | 오른쪽 목록에서 왼쪽 트리로 |
| Enter | 폴더 펼치기 / 선택 항목 실행 |
| Tab | 메뉴 트리 → 항목 목록 → 검색 순환 (Shift+Tab 역순) |
| F1 | 연결 설정과 도움말 |
| F2 | 선택한 입력란 편집 |
| F3 | 현재 읽은 메뉴·항목 찾기 (서버 전체 검색 아님) |
| F4 | 연결한 원본 브라우저 탭 표시 |
| F5 | 현재 DOM 다시 읽기 (서버 조회 아님) |
| F6 | 현재 화면의 표 보기 / Esc로 복귀 |
| F7 | 이번 연결의 읽기 전용 ↔ 조작 허용 |
| F8 | ‘저장’ 항목 찾기 (자동 저장 안 함) |
| F9 | 업무 시작 주소 열기 |
| Ctrl+F4 | 기관 업무 탭 전환(새 창으로 열린 업무 탭 연결) |
| F10 / F11 / F12 | 종료 / 최대화 / 설정 |
| Esc | 표 닫기 → 검색 해제 → 메뉴 트리로 |

## 실제 데이터 연결 방식

```text
사용자 키 입력
  → Windows WPF 앱 (자체 업무 DB 없음)
  → 현재 Windows 사용자 전용 Named Pipe
  → Native Messaging 호스트
  → 사용자가 직접 연결한 Chrome/Edge 확장
  → 실제 로그인된 탭의 DOM 입력·클릭
  → 기존 K-에듀파인 웹 애플리케이션이 원래 방식으로 서버 처리
```

공식 API를 얻었다고 가정하지 않고, 내부 비공개 API를 추정 호출하지 않습니다. **웹 버튼 클릭 전달 ≠ 서버 저장 성공**입니다. 저장 결과는 원본의 메시지와 재조회로 확인해야 합니다.

## 개인정보·보안

- 외부 AI, 클라우드 서버, 분석/광고/텔레메트리 SDK 없음. 로컬 HTTP/WebSocket 수신 포트도 없음.
- 인증서·비밀번호·숨김 토큰·파일 입력을 읽거나 전송하지 않음. 보호된 이름의 입력과 주민번호 형태 문자열을 필터링함.
- 원본 브라우저의 로그인 세션과 쿠키를 **추출하거나 다른 브라우저로 복사하지 않음**.
- 웹 내용은 메모리 표시 전용. `%LOCALAPPDATA%\M-Edufine\settings.json`에는 시작 주소와 글자 크기만 저장.
- 확장은 사용자가 연결한 한 탭에 고정. `javascript:`/`#` 같은 같은 문서 링크는 사이트 자체 핸들러로 실행하지만, `file:`·사용자 정의 스킴 등 외부 앱 링크는 차단합니다.
- 시험용 합성 데이터(`--ui-demo`)는 실제 기관과 연결되지 않으며 화면에 합성임을 표시합니다.

## 개발·빌드

.NET 10 SDK와 Windows에서:

```powershell
dotnet publish '.\src\MEdufine\MEdufine.csproj' -c Release -r win-x64 --self-contained true -o '.\publish'
Copy-Item '.\extension' '.\publish\extension' -Recurse -Force
Copy-Item '.\native-host.json' '.\publish\native-host.json' -Force
& '.\publish\M-Edufine.exe' --self-test
& '.\publish\M-Edufine.exe' --ui-demo --smoke-test
```

전체 패키지는 `.github/workflows/windows.yml`에서 코드 검사 → Chromium DOM 테스트 → Windows .NET 빌드 → 네이티브 통신 테스트 → WPF 렌더 스모크 → Inno Setup 설치·제거 시험 → Preview Release 순으로 만듭니다.

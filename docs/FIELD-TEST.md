# 기관 PC에서의 현장 검증

현재 프리뷰는 실제 K-에듀파인 로그인 후 전체 호환성을 보장하지 않습니다. 기관 허용 범위 안에서 실시하세요.

## 1. 읽기 전용부터

- [ ] Windows 설치가 일반 사용자 권한으로 완료된다.
- [ ] 기관 정책상 확장 및 Native Messaging 사용이 허용된다.
- [ ] Edge 확장 ID가 `extension-id.txt`와 같다.
- [ ] 실제 원본 탭에서 인증서 로그인을 완료한다. 앱에 인증서를 복사하지 않는다.
- [ ] 해당 탭에서 연결 후 앱 F5를 누르면 실제 항목과 제목이 맞는다.
- [ ] 한글, 125/150% DPI, F3 검색, 방향키, Enter, Tab, Esc가 작동한다.
- [ ] F4는 연결한 정확한 탭을 연다. 다른 탭 자료가 섞이지 않는다.
- [ ] 연결 해제/페이지 전환/로그아웃/탭 닫기 후 이전 항목이 남지 않는다.
- [ ] 실제 웹 표와 앱 표를 비교하고 가상 스크롤·잘림·누락을 기록한다.

## 2. 조회 동작

- [ ] F7을 명시적으로 허용한 뒤 승인된 메뉴를 선택한다.
- [ ] 실제 조회 조건이 맞는지 확인한다. 편집값의 여러 줄/공백이 보존된다.
- [ ] 조회 버튼을 실행한 뒤 원본에서 조회 결과를 확인한다.
- [ ] F5로 읽은 결과가 원본과 일치한다.

## 3. 시험 자료로만 저장 검증

- [ ] 운영기관이 승인한 시험 대상과 취소/복구 절차가 확보되어 있다.
- [ ] 변경 전 실제 값을 기록하고 입력·클릭 확인창을 검토한다.
- [ ] 원본의 저장 메시지 확인 후 실제 조회를 다시 실시해 서버 반영을 확인한다.
- [ ] 새로 로그인한 세션에서도 값이 맞는지 확인한다.
- [ ] 실패·시간초과에서는 저장을 중복 누르지 않는다. 서버 반영 여부부터 확인한다.

실제 지출·지급·결재·삭제로 시험하지 마세요. 표가 안 보이거나 버튼이 동작하지 않으면 F4를 사용하고 해당 화면의 어댑터를 별도 개발해야 합니다.

## 보고할 수 있는 정보

앱 버전, Windows/Edge 버전, 메뉴의 일반 명칭, 인식 수/접근 불가 프레임 수, 오류 유형만 기록합니다. 인증서·쿠키·비밀번호·HAR·토큰·주민번호·실제 업무 데이터가 들어간 스크린샷은 GitHub 이슈에 올리지 마세요. 필요하면 개인정보를 제거한 별도의 시험 화면을 만듭니다.

## 5. 알려진 제한

1. **새 창을 여는 메뉴**: 합성 클릭은 Chrome의 사용자 활성화(user activation) 요구를 충족하지 못해 `window.open` 팝업이 차단될 수 있습니다. 원본에서 한 번 연 뒤 **Ctrl+F4**로 연결하세요.
2. **메뉴 누락**: 추출기는 확인된 패턴(내비게이션 영역, role, 위임 클릭, 이미지 alt)만 사용합니다. 구조가 다른 위젯은 표시되지 않으며 F4가 필요합니다.
3. **계층 평탄화**: DOM 중첩이 없는 별도 패널 메뉴는 상위 경로가 만들어지지 않을 수 있습니다(예: 좌측 LNB 항목이 루트로 표시).
4. **서버 조회/저장**: F5는 DOM 재읽기입니다. 조회 결과 일치, 저장 성공은 실제 계정에서 검증하지 않았습니다.

## 6. 데이터 취급

- 실제 업무 데이터는 메모리에만 표시했고 저장·전송하지 않았습니다.
- 시험 중 캡처는 로컬 작업 폴더에만 두었고 저장소·릴리스에 포함하지 않았습니다.
- 결재·지급·삭제·등록 등 운영 데이터 변경은 실행하지 않았습니다.

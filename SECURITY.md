# Security policy

This preview has not received a production security audit or K-Edufine operator approval.
Do not attach certificates, passwords, tokens, cookies, HAR captures, financial records, resident identifiers or unredacted screenshots to issues.

Use the app only where your institution authorizes it. Do not bypass extension policy, network restrictions, certificate validation or authentication.

The app stores preferences only; browser sessions remain in the original browser. It exposes no HTTP/WebSocket listener. The named pipe is restricted to the current Windows user. A malicious process already running as that user is outside this isolation boundary.

Never assume a dispatched DOM click proves a persisted server change. Timeout or disconnect must not trigger an automatic write retry.
